# Hey, I'm Meer 👋

I build integrations, untangle data, and try to make complicated systems a little easier to live with.

Most of my work sits where healthcare, APIs, Lua, and SQL meet. I enjoy figuring out why a message went sideways—and building tools that make the next mystery easier to solve.

## Things I've built 🔧

| Project | What it does |
| --- | --- |
| [Iguana Stats Collector](https://github.com/Ushter/iguana-stats-collector) | Collects API metrics and brings them together in SQLite. |
| [Database-driven X12 Validator](https://github.com/Ushter/x12-database-validator) | Uses database rules to check segment order, groups, identifiers, and repeats. |
| [Iguana X Log API Example](https://github.com/Ushter/iguanax-log-api-example) | Connects session authentication, error logs, and component details in one workflow. |
